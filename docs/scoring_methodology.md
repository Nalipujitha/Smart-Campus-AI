# Composite Student Success Scoring Methodology

## 1. Overview
The Student Success Score is a transparent, explainable composite metric calibrated on a standardized 0–100 scale. It empowers faculty mentors and academic deans with actionable early-warning insights.

## 2. Default Indicator Weight Distribution

| Indicator Component | Proposed Weight | Normalization Methodology |
|:---|:---:|:---|
| **Academic Performance** | 30% | Normalized GPA (0–10 scaled to 0–100) with backlog penalty (-10 points/backlog). |
| **Attendance Record** | 20% | Institutional attendance percentage across eligible sessions. |
| **Placement Readiness** | 15% | Composite readiness across Coding (35%), Aptitude (25%), Communication (20%), and Interview (20%). |
| **LMS Digital Activity** | 10% | Average course module completion percentage (50%) + Quiz performance average (50%). |
| **Co-Curricular Engagement** | 10% | Accumulated activity points (Hackathons, Workshops, Sports, Clubs) normalized to 100. |
| **Skills Assessments** | 10% | Technical programming drills and aptitude problem-solving scores. |
| **Faculty Behavioral Feedback** | 5% | Punctuality, teamwork, initiative, and faculty mentoring evaluations. |
| **Total** | **100%** | **Composite Weighted Sum** |

## 3. Risk Classification Boundaries
- **Low Concern (Good Standing)**: Success Score ≥ 75.0
- **Medium Concern**: 50.0 ≤ Success Score < 75.0
- **High Concern (Active Support Needed)**: Success Score < 50.0

*Note: Triggers also independently evaluate domain-specific criteria (e.g. Attendance < 75% or GPA < 6.0) regardless of the overall composite score.*
