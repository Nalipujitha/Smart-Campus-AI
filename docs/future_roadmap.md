# Smart Campus Analytics - Future Commercial Roadmap

This roadmap outlines the planned technical expansion as Smart Campus Analytics transitions from a local institutional platform into a multi-tenant enterprise SaaS startup.

## Phase 1: Institutional Core (Current)
- [x] Local-first Flask + SQLite backend with decoupled service architecture.
- [x] Full student lifecycle monitoring (Attendance, Academics, LMS, Placement, Mentoring).
- [x] Explainable 7-factor Success Scoring and transparent risk triggers.
- [x] Local-grounded AI Campus Assistant and Career Matching engine.
- [x] Comprehensive Pytest test suite and reproducible synthetic datasets.

## Phase 2: Enterprise Multi-Tenancy & Database Migration
- [ ] PostgreSQL migration with schema-based tenant isolation.
- [ ] Role hierarchy with fine-grained granular permissions (Department Chairs, Lab Assistants, TPOs).
- [ ] Real-time bi-directional LMS synchronization via LTI (Learning Tools Interoperability) for Moodle, Canvas, and Blackboard.

## Phase 3: Advanced AI & Automated Workflows
- [ ] Optional LLM connector (OpenAI / Google Gemini / Ollama local models) for natural language report synthesis.
- [ ] Automated SMS/WhatsApp notifications for critical attendance alerts.
- [ ] Resume parsing and automated mock video interview analysis.
- [ ] Automated institutional accreditation reporting (NAAC / ABET metric exports).
